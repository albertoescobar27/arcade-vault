## Stack / architecture

- Next.js 16.4 (App Router, `app/` dir), React 19.3, TypeScript strict, Tailwind CSS v4.
- **Next 16 differs from training data** — check `node_modules/next/dist/docs/` (`01-app`, `03-architecture`, …) before using any Next API.
- `next.config.ts` enables `cacheComponents`, `partialPrefetching`, and `experimental.agentFeedback`. Cache Components changes data-fetching/caching semantics (dynamic vs cached rendering, `"use cache"`); read the docs before writing data-fetching code.
- Tailwind v4 is wired through a Turbopack loader rule (`@tailwindcss/turbopack` on `*.css`), not PostCSS. Theme tokens live in `app/globals.css` via `@import "tailwindcss"` + `@theme inline` (no `tailwind.config`).
- Layout props use Next's global typed helpers (e.g. `LayoutProps<"/">`), generated by `next dev`/`next build`.
- Path alias `@/*` → repo root.
